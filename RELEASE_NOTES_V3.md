# V3 — Procedural Host & Qualification Expansion

## Host elections

- Athens 1896 remains the only fixed host.
- Every later Games uses a four-city, three-round host election.
- One bid is visibly eliminated per round.
- No consecutive host continents.
- Bid scores use facilities, pathways, support, sustainability and legacy, with ballot uncertainty.
- Host victories create a large, decaying national investment legacy.
- Host proposals can add era-plausible programme events.
- Host country changes the visual palette and typography of the Games and Programme pages.

## Alternate Olympic history

- The universe now stages an Olympiad every four years, including 1916, 1940 and 1944.
- Historical programmes remain the era baseline without forcing historical hosts or results.
- Programme safeguards prevent clearly anachronistic host additions.

## Qualification expansion

- Fixed the sport-filter delegation-count bug.
- Added named qualification circuits with venues and routes.
- Every Olympic discipline has a qualification competition.
- Every qualified athlete has a stored pathway.
- Competition detail includes disciplines, participants, places, countries and athletes.
- World records can fall during qualification.
- Added current qualification record view and historical qualification archive.

## Competition and records

- Added explicit one-day simulation.
- Added daily WR/OR notification panels.
- Added record badges to medal-result cards.
- Added Olympic/qualification record source filtering.

## Medals and countries

- Added current medal-table sport filtering.
- Added historical sport-specific medal rankings.
- Added a cumulative four-country medal-evolution graph.
- Added permanent individual medal archive.
- Expanded country pages with edition breakdown, sport breakdown, every medal, active athletes and all medalists.
- Generational rarity is now red.

## World events

- Six cycle events appear before each Games.
- Added a real 144-scenario pool.
- Events alter national investment, youth, facilities, sport strength and sometimes delegation depth.
